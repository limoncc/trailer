description: 实验的 Markdown 报告,支持 CRUD
---

Reports(`/reports`)让你围绕实验写 Markdown 总结。

## 特性

- **创建 / 编辑 / 删除** 报告
- **Markdown 渲染** + 代码高亮(MarkdownRenderer 组件)
- 报告**按 owner 隔离**——每个用户只看自己的

## 用法

1. 进入 `/reports` → **New Report**
2. 写 Markdown(支持表格、代码块、链接)
3. 保存;从报告列表随时回顾

报告与 Explore 互补:报告是叙述性总结,Explore 是分析性工作台。

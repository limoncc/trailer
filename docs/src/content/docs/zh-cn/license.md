Trailer 采用 **Elastic License 2.0**。

## 你能做什么

- 免费使用 Trailer 记录、查看你的 ML 实验
- 个人 / 公司内部使用(包括商业团队内部使用)
- 复制、修改、fork 源码,贡献代码
- 随你的项目再分发(保留版权声明)

## 你不能做什么

- **对外提供托管服务(SaaS)**:不得把 Trailer 作为多租户云服务 / 托管服务提供给第三方
- 移除 / 隐藏版权与许可声明
- 绕过许可保护功能

## 商业授权

如需超出 Elastic License 2.0 的授权(例如提供 Trailer 托管服务、嵌入式商业分发),请联系 **limoncc@icloud.com**。

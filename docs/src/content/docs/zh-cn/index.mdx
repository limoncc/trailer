## 快速上手

```bash
pip install trailer-sdk
```

```python
from trailer import Tracker

t = Tracker(project="demo")
for step in range(10):
    t.log({"loss": 1.0 / (step + 1)}, step=step)
t.finish()
```

```bash
trailer up   # 打开 http://127.0.0.1:5120
```

## 工作原理

<div class="flow">
  <span class="flow-step">Python SDK</span><span class="flow-arrow">→</span>
  <span class="flow-step">Rust Ingest</span><span class="flow-arrow">→</span>
  <span class="flow-step">SQLite / PostgreSQL / 文件</span><span class="flow-arrow">→</span>
  <span class="flow-step">Web UI</span>
</div>

数据经环形缓冲攒批,通过 PyO3(本地)或 HTTP(远程)进入 Rust 核心,再提供给 Web UI。

## Quick start

```bash
pip install trailer-sdk
```

```python
import random
from trailer import Tracker

tracker = Tracker(project="my_training")
for step in range(100):
    base = 0.9 * 0.96 ** step
    tracker.log({"train/loss": base + random.random() * 0.04,
                 "val/loss": base + 0.06 + random.random() * 0.06},
                step=step)
tracker.finish()
```

```bash
trailer up   # open http://127.0.0.1:5120
```

## How it works

<div class="flow">
  <span class="flow-step">Python SDK</span><span class="flow-arrow">→</span>
  <span class="flow-step">Rust Ingest</span><span class="flow-arrow">→</span>
  <span class="flow-step">SQLite / PostgreSQL / File</span><span class="flow-arrow">→</span>
  <span class="flow-step">Web UI</span>
</div>

Data is buffered in a ring buffer and flushed in batches through PyO3 (local) or HTTP (remote) into the Rust core, then served to the web UI.

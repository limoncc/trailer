Reports (`/reports`) let you write Markdown summaries around your experiments.

## Features

- **Create / edit / delete** reports
- **Markdown rendering** with code highlighting (MarkdownRenderer component)
- Reports are **owner-scoped** — each user sees their own

## Usage

1. Go to `/reports` → **New Report**
2. Write Markdown (tables, code blocks, links supported)
3. Save; revisit from the reports list

Reports complement Explore analyses: reports are narrative, Explore is analytical.
